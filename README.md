# عَون AWN | منصة الاستجابة الإسعافية الذكية

«لأن كل ثانية تصنع فرقًا، وكل معلومة قد تنقذ حياة»

نموذج أولي لمسار الجاهزية الطبية العسكرية: رمز QR ثابت على الزي العسكري يبدأ بلاغًا إسعافيًا، ومساعد يرشد المستجيب الأول خطوة بخطوة ويوثّق كل إجراء بتوقيته، ثم يستلم المسعف المخوّل السجل نفسه بمسح الرمز نفسه.

## الملفات
| الملف | المحتوى |
|---|---|
| `index.html` | الصفحة |
| `app.js` | منطق المنصة: التسجيل، البلاغ، لوحة الفريق الطبي، المؤشرات، العمل دون اتصال |
| `app.css` | الهوية البصرية والتصميم |
| `qrcode.js` | توليد رموز QR (مكتبة qrcode-generator، رخصة MIT) |
| `fonts/` | الخطوط مستضافة محليًا (رخصة OFL) |
| `_headers` | ترويسات الأمان على Netlify |

## التجربة
- موقع ثابت بلا خادم، ينشر على Netlify مباشرة (لا يحتاج أمر بناء).
- البيانات تُحفظ في متصفح كل جهاز. العسكريون الثلاثة الافتراضيون لهم معرّفات ثابتة، فمسح رموزهم من أي جهاز يفتح صفحة البلاغ.
- رمز دخول الفريق الطبي التجريبي: `2026`.

جميع البيانات افتراضية، والإرشادات الإسعافية نص تجريبي يلزم مراجعته واعتماده من مختصين قبل أي استخدام.
